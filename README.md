# Crystal Bikes

A website for a motorcycle club: rides, events, photo gallery, and a way for new riders to join.

**Live demo:** https://motoclub.pages.dev

![Crystal Bikes screenshot](screenshot.png)

## Features

- Club introduction and history
- Upcoming rides and events
- Photo gallery
- Contact or join form for new members
- Fully responsive for phones
